# NewPay

NewPay é uma aplicação desenvolvida em Flutter com a proposta de simular um banco digital simples, moderno e funcional.

O projeto foi criado como atividade final da disciplina, atendendo aos requisitos de criação de telas, uso de banco de dados, consumo de API, uso de plugins, rotas nomeadas, rotas com argumentos e geração de APK.

A ideia do aplicativo é oferecer uma experiência próxima de um banco digital real, permitindo login, cadastro, visualização de saldo, consulta de cotações, transferências, leitura de QR Code Pix e compartilhamento de comprovante.

---

## Sobre o Projeto

Este projeto foi desenvolvido em Flutter e serve como uma aplicação prática para demonstrar conceitos importantes de desenvolvimento mobile.

O NewPay possui uma interface escura, com detalhes em verde, buscando transmitir uma identidade visual moderna, tecnológica e objetiva.

Além de funcionar como aplicativo mobile, o projeto também pode ser executado em ambiente Web para testes durante o desenvolvimento.

## Funcionalidades

O aplicativo possui as seguintes funcionalidades:

- Tela de login
- Tela de cadastro de usuário
- Tela de carregamento após login ou cadastro
- Tela principal com saldo disponível
- Histórico de transferências realizadas
- Tela de cotação de moedas
- Consumo de API externa para buscar cotações
- Tela de transferência
- Leitura de QR Code Pix usando a câmera
- Compartilhamento de comprovante de transferência
- Banco de dados local
- Rotas nomeadas
- Rotas nomeadas com argumentos
- Suporte para execução em Web e Android
